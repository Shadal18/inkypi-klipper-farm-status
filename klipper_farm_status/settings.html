🖨️ Klipper farm status

Monitor multiple Moonraker printers from one shared dashboard.

Add one or more Moonraker endpoints, choose the print and spool details to display, and render a farm-wide status board for your e-paper screen.

🔗

Add Moonraker printers

Each printer needs a reachable Moonraker URL, such as http://printer.local:7125. Camera snapshots are optional and only needed when the default /webcam/?action=snapshot path is not correct.

🖨️

Dashboard and printers

Set the board title and configure each Moonraker printer.

Optional. Leave blank to use the default Klipper Farm heading.

Printers

Disable a printer to keep its configuration without including it on the farm display.

⚙️

Display options

Choose which printer details appear on the farm board.
Camera image

Display a still snapshot from each printer webcam.

Progress

Display each printer’s current progress percentage.

File name

Display the current file name for active jobs.

ETA

Display estimated remaining print time.

Layers

Display current and total print layers when available.

Temperatures

Display hotend and bed temperatures.

Active spool

Display the spool assigned to the printer.

Spool brand

Display spool vendor or brand information.

Spool material

Display filament material for the active spool.

Spool remaining

Display remaining spool weight when available.

Status message

Display Moonraker state or status messages.
