Display options
Choose which printer details appear on the farm board.
Show Progress
Display each printer’s current progress percentage.
Show File Name
Display the current file name for active jobs.
Show ETA
Display estimated remaining print time.
Show Layers
Display current and total print layers when available.
Show Temperatures
Display hotend and bed temperatures.
Show Active Spool
Display the spool currently assigned to the printer.
Show Spool Brand
Display spool vendor or brand information.
Show Spool Material
Display filament material for the active spool.
Show Spool Remaining
Display remaining spool weight if available.
Show Status Message
Display Moonraker state or status messages.
